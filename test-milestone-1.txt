VidFetch - milestone 1: the downloader
=====================================

Why: your request for VidFetch, and log.md, entry 1, which says what was built and what I tried.

How to start it: run
C:\Users\ldefo\dev\VidFetch\target\release\vidfetch.exe
It is the first run on this computer, so it starts with a welcome. Downloads go to Videos\VidFetch in
your user folder; you can choose another folder in the File menu. Nothing costs anything. The test
uses public videos from YouTube; section 4 downloads about 10 minutes of sound, which takes a minute
or two.

---------------------
