7.2  Anything else you would want a downloader to do?
ANSWER:
Feature requests:
1. Implement the ability to search Youtube. Search results are listed, pressing enter on a result starts streaming the audio with the built-in player. Pressing ctrl+d adds the video to the download queue to be downloaded with currently active settings. A context menu also enables these actions. Pressing escape exits search.
2. Implement the ability to follow channels, making it possible to go to a list of followed channels and see what is new and to stream or download videos as above. The information re followed channels should be kept locally, no account sign-in required. Suggest best mechanisms for adding channels to the followed channels list, e.g. from search.
3. Implement the type of categories management found in NoteFetch. This should make it possible to organise downloads by different categories, e.g. Tech, News, Music, Documentaries, Language Learning, whatever the user wants to create. Copy from NoteFetch to implement this.
4. Search for what else blind users would really like and appreciate in a video downloader/streamer for Windows and come up with a list of features we can prioritise together.
